Notifications (ntfy)

Health alerts, the daily digest and the heartbeat go to an ntfy topic; subscribe to the same topic in the ntfy app. Anyone who knows the topic can read and post to it, so it is never shown again after saving: leave the topic and token empty to keep the saved ones.

Heartbeat (dead-man's switch)

The Pi keeps re-arming a delayed ntfy message. If it stops checking in (power loss, crash, network down, or failing scheduled captures), ntfy delivers the message after the alert delay.
